# LifeLens

一个完全在本机运行的桌面应用：定时截屏，用本地视觉模型看懂你在做什么，并把一天整理成可检索的记忆。

截图、记录和模型推理都在你自己的电脑上，不依赖任何云端 AI 服务。

## 功能

- **今日与主动提醒**：打开就是“今日”页：今天的时间分配、上次停在哪、待办收件箱。应用会在三个时刻主动提醒：早上告诉你上次做到哪，白天提醒可能漏掉的待办，晚上给出当天小结。每类提醒都可以关，每天有总量上限。
- **截屏记录**：每 20 秒截取所有屏幕（支持多显示器），本地模型用 5 句话总结当时在做什么。
- **动态**：每 10 分钟做一次结构化汇总（项目名称、分类、描述、用到的软件、可能遗漏的待办），以热力图和时间线展示，可按项目、软件、时间筛选。
- **日记**：把一天的 10 分钟汇总再汇总成日记：简短总结、三件主要事项、高光、待办、优化建议、温馨提示。
- **看板**：按天 / 周 / 月 / 年查看时间分配、项目专注时间、软件使用、活跃时段等图表。
- **问答**：向本地模型提问。模型自己决定搜哪种记录、什么关键词、哪段时间，最多搜 3 次后回答。
- **空闲检测**：一段时间没有键鼠操作且画面没变时不记录；统计按真实活跃时间计算。
- **截图管理**：截图默认只保留最近 3 天，也可以一键清理当天或全部；文字记录始终保留。
- **暂停与删除**：可以暂停记录一段时间（全局快捷键 `Ctrl+Alt+P`），也可以删除任意一段时间的全部记录。
- **多设备同步**（可选）：用你自己的私有 Git 仓库在多台电脑之间同步文字记忆，截图不同步。

## 运行要求

- Windows 10 / 11（目前只在 Windows 上开发和测试过）
- [Node.js](https://nodejs.org/) 22.12 或更高版本
- 一个提供 OpenAI 兼容接口、**支持图片输入**的本地模型服务，例如带 `--mmproj` 的 llama.cpp `llama-server`，默认地址 `http://127.0.0.1:8080/v1`。模型还需要支持 `response_format` 的 `json_schema` 结构化输出。
- 可选：在“设置 → 本地模型”里选一个启动脚本（`.ps1`、`.cmd`、`.bat` 或 `.exe`）并勾选“打开 LifeLens 时自动启动模型”。打开应用时如果模型服务不在线，LifeLens 会运行这个脚本并等服务上线；模型不会随 LifeLens 退出而关闭。
- 使用多设备同步时需要安装 Git，并能免交互访问你的仓库。

## 开始使用

```bash
npm install
npm start
```

打包成独立的 `LifeLens.exe`，安装到 `%LOCALAPPDATA%\Programs\LifeLens` 并创建桌面图标：

```bash
npm run release

做一个可以发给别人的安装包（双击即可安装，带桌面图标和卸载入口）：

```bash
npm run dist
```

产物在 `dist/installer/LifeLens-Setup-版本号.exe`。安装包没有代码签名，第一次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息 → 仍要运行”即可。在中国大陆构建较慢时，可以设置 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。
```

## 数据存在哪里

默认在 `文档\LifeLens`，可以在设置里修改：

```
LifeLens/
  2026-11/
    2026-11-10_18.json            每小时一个文件：每次截屏的时间、图片路径、活动总结
    screenshots/2026-11-10/       截图
    summaries/2026-11-10.json     每天一个文件：10 分钟汇总
    diary/2026-11-10.json         每天一个文件：日记
  sync/                           开启多设备同步后的 Git 仓库副本
```

## 隐私

LifeLens 会截下屏幕上的一切，包括密码、聊天内容和私人文件。

- 不开启同步时，所有数据只存在本机，应用只连接你配置的本地模型地址。
- 开启多设备同步后，10 分钟汇总和日记的文字会推送到你填写的 Git 仓库。请只使用私有仓库：应用每次同步前会检查，发现仓库可以被匿名读取（即公开仓库）就拒绝同步。
- 截到不该截的内容时，可以删除那段时间的全部记录。删除会同步到远程仓库，但仓库的历史提交里仍能找到旧内容；如果涉及密码，请同时修改密码。
- 输入敏感内容之前，可以先用 `Ctrl+Alt+P` 停止记录。
- 请只在你自己的电脑上、在你本人知情的情况下使用，不要用它记录他人的屏幕。

## 项目结构

| 文件 | 作用 |
|---|---|
| `src/main.js` | 主进程：定时截屏、分析队列、窗口与托盘 |
| `src/capture.js` | 多屏截图 |
| `src/analyzer.js` | 调用本地模型分析截图 |
| `src/launcher.js` | 运行用户选的脚本来启动本地模型 |
| `src/storage.js` | 按月 / 小时存储记录，清理截图 |
| `src/summarizer.js` | 10 分钟汇总 |
| `src/diary.js` | 日记 |
| `src/dashboard.js` | 看板统计 |
| `src/qa.js` | 问答：搜索循环与每日一行索引 |
| `src/sync.js` | Git 多设备同步 |
| `src/renderer/` | 界面 |

问答里“每天一行”的记忆索引，思路借鉴自 [AOCI-CODE](https://github.com/aoci-spec/aoci-code)（固定字段、一行一条、先整体读一遍再去查原文），没有使用它的代码。
